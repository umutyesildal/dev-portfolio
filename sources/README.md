# Sources

Drop the raw material for your portfolio here. Everything in this folder is
git-ignored except this README and `notes.example.md`.

## What to put here

- `cv.pdf` (or `cv.docx`, `cv.txt`) — your current CV.
- `linkedin.pdf` — LinkedIn's official "Save to PDF" export.
- `linkedin.html` — optional alternative: a saved copy of your profile page.
- `notes.md` — anything the CV and LinkedIn miss (target roles, projects to
  feature, tone, links).
- `github.json` — generated by the importer, do not edit by hand.

## LinkedIn export

LinkedIn blocks direct scraping, so use the official export:

1. Open your profile on LinkedIn.
2. Choose **More → Save to PDF** (or **Resources → Save to PDF**).
3. Move the file to `sources/linkedin.pdf`.

If you already saved the profile as HTML, `sources/linkedin.html` works too.

## GitHub import

```bash
pnpm profile:github your-username
```

This writes `sources/github.json` with your public profile and repositories.
For a higher API rate limit, run it with a token:

```bash
GITHUB_TOKEN=ghp_... pnpm profile:github your-username
```

## Build the profile

Open your coding agent in this repository and say:

```text
Build my portfolio from sources/. Follow AGENTS.md and
skills/portfolio-builder/SKILL.md. Use only facts present in the sources,
and ask me for anything missing.
```

Then run:

```bash
pnpm profile:check
pnpm build
```

`profile:check` fails if placeholder text, missing assets, or `example.com`
links are still present. `content:check` only validates the schema and assets;
use it for the template demo.
